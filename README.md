# Simple Static Site

This is the beginner-friendly version of the Sushi Bar Osaka website.

## Files

- `index.html` - all content and structure
- `styles.css` - all visual styling
- `script.js` - small interactions only

## Why this version is simpler

- No framework
- No build step
- No package manager needed
- Easy to edit prices, text, and sections directly

## Open it

You can open `index.html` directly in a browser.

If you want to serve it locally from a terminal, run this inside the `simple-static-site` folder:

```powershell
python -m http.server 8080
```

Then open `http://localhost:8080`.
